# Palama Campus Rides

I'm creating a platform for student rides called Palama. Which is a ride service similar to Uber, Indrive, and Yango. The platform is tailor made to students. Create a visually stunning site with smooth animations. The site should have the following pages

Home
Settings

Once in a ride the app should show you the distance from collection point to the destination and give the ability to share location with anyone of your choosing. 

The app should also have a provider section which is the people offering the rides

Extra Context
-Add all local universities in Botswana
-The platform doesn't cover a distance of over 65km
